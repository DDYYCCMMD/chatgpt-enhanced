## 安装及更新

需要 Node.js 22.18+、npm、Chrome 111+。

```sh
npm ci
npm run typecheck
npm test
npm run build
git diff --check
```

在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”并选取仓库的 `dist/`。更新已有安装时先重载扩展，再刷新实际 ChatGPT 标签页；只重开弹窗不会替换旧脚本。检查弹窗与当前页诊断版本为 0.3.1，已有颜色和开关应保留。

三个核心功能默认关闭，各自启用。本地备份独立、默认关闭：开启后仅保存有界问题预览、标识和位置提示，最多八会话、各 300 条；不是完整对话备份，不存助手回答或会话布局测量。停止备份保留旧记录，清除按钮则关闭并删除备份。

## 已知限制

- 未挂载历史依赖网页加载，冷启动可能耗时数秒；扫描及目录不保证涵盖所有服务端历史。
- 超时、删除、编辑分支或身份/布局不稳定可能安全定位失败，恢复也可能只能返回原位置附近。
- 原有实页证据仅一个 17 问题会话，部分目标有 2s/8s 延迟检查。本轮没有新增登录后实页验证。
- 其他账号、项目/GPT、流式回复、编辑分支、慢网络及各种窗口布局仍需广泛实测；不能宣称普遍提速百分比。
- ChatGPT 未公开 DOM 可能变化；扩展仅使用 `storage` 权限和 `https://chatgpt.com/*` 内容脚本，无后端、OpenAI API、遥测或运行时外部网络请求。
