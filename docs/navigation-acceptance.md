# V0.3.1 实页验收矩阵 — 2026-11-26

本轮执行了代码审查和自动化回归，未执行登录后的真实 ChatGPT 页面验收。下表全部为**未验证**，供用户在安装本轮 `dist/` 后执行。此前一个 17 问题会话的结果仍见 [实页记录](navigation-live-verification.md) 和 [性能跟进](navigation-performance-verification.md)，不自动沿用为本版通过。

## 准备及记录条件

1. `npm ci`、`npm run build`，在 `chrome://extensions` 加载或重载 `dist/`，刷新真正的 ChatGPT 标签页。弹窗和“检查当前页”应显示 0.3.1，三个功能默认关闭，已有设置保持。
2. 使用独立测试数据。分别准备短会话、会虚拟化的长会话、项目内会话及自定义 GPT 会话；不要为了验收删除用户现有备份。发送/编辑/分支只在自己选择的测试会话中进行。
3. 每次记录 Chrome/系统版本、扩展版本、会话类型（用匿名编号）、功能及备份开关、窗口/视口 CSS 尺寸、缩放、侧边栏状态、DevTools 停靠、网络条件和缓存状态（刷新冷加载/已扫描/目标已挂载）。不要存储真实问题文字或 ID。
4. 定位使用真实鼠标点击，记录页面焦点与输入方式；Console 的 `button.click()` 单独记录，不能等同真实点击或用于混合性能比较。键盘测试也单列。
5. 从点击开始，分别记录首次正确到达时间与稳定确认完成时间；确认同一原消息身份和头部留白，完成约 2s、8s 后再看是否回退。若失败，记录固定状态文字、耗时、精确恢复/近似恢复/用户接管，以及是否还能继续操作。不要把目标短暂出现计为通过。
